# 12_04｜权重空间编程进阶

[全部教程](../../README.md) · [进阶功能路线](12_进阶功能路线.md) · [上一篇：12_03｜残差强化学习进阶](12_03_残差强化学习进阶.md)

## 这一部分介绍什么

让大模型检查 SmolVLA 的一小部分权重，并提出修改。以推块为例，蓝区目标不变，只把指令里的 `blue target zone` 改成 `blue area`。如果模型原本能完成任务，换个说法就反复失败，就尝试修补 `area` 对应的一行语言嵌入。脚本直接应用数值补丁，并用仿真闭环检验，整个过程无需反向传播。 [权重空间编程原始实验](https://rikiyat.github.io/blog/weight-space-programming/) · [机器人策略权重编辑实验](https://arxiv.org/abs/2611.09376)

## 使用说明与前提

准备好阶段 03–04 的运行目录及阶段 05_01 的本地模型和处理器。在已有的 `embodiedai` 环境中，从 Git 仓库根目录运行：

```bash
python smol_workflow/p12_advance/12_04_edit_weights.py --run-dir outputs/lesson_run --device auto
```

默认诊断基础模型。要检查已经能完成原指令的浮点策略，可在诊断时加 `--base-checkpoint outputs/lesson_run/models/merged`。默认诊断集和留出集各取两个种子，每个种子都测蓝区和绿区。若只检查脚本能否启动，可用 `--max-steps 1 --seeds-per-split 1` 做短回合，正式诊断时使用新实验目录并去掉这两个参数。

打开 `outputs/lesson_run/models/wsp/diagnosis.json`。当 `reproduced` 为 `true` 时，说明同一目标至少有两个初始场景出现「原指令成功、改写失败」。把 `diagnosis.json` 和 `patch_template.json` 给负责编辑的大模型。这一步由你选择并调用大模型，脚本通过 JSON 交接。留出测试保存在 `experiment.json`，挑补丁时只给编辑者看诊断数据。

可给编辑者这条指令：

> 根据配对回合结果和语言嵌入，为 `area` 提出一份 JSON 权重补丁。保留模板中的 `diagnosis_sha256`。填入诊断中 `zone`、`target` 或 `region` 的 `reference_token_id`，选择大于 0 且不超过 1 的 `strength`，并在 `reason` 中说明依据。只返回 JSON。若诊断不能定位问题，报告原因。

也可以提交稀疏数值补丁，用 `deltas` 替换 `reference_token_id` 和 `strength`。例如 `"deltas": {"12": 0.005}` 表示给 `area` 嵌入行的第 12 个坐标加上 0.005，坐标从 0 开始。最多允许 32 个坐标，改变量的 L2 范数不能超过原嵌入行的 L2 范数。保留模板中的 `diagnosis_sha256` 和 `reason`。

将大模型生成的 JSON 保存为 `outputs/lesson_run/models/wsp/proposed_patch.json`，再运行：

```bash
python smol_workflow/p12_advance/12_04_edit_weights.py --run-dir outputs/lesson_run --patch outputs/lesson_run/models/wsp/proposed_patch.json
```

应用时沿用诊断所用的检查点和仿真配置。两个步骤如需改存其他位置，都传入同一个 `--experiment-dir`。完成后的实验和对照报告各只写一次，失败时可以重试同一条命令。

## 输入和输出

- **诊断输入**为原指令、同义改写、同一初始场景、同一推理噪声和浮点检查点。**诊断输出**包含配对回合结果、相关词元的权重行、补丁模板和回放。
- **补丁输入**为绑定本次诊断哈希的 JSON。**补丁输出**写在 `comparison/`，包含补丁副本、三个策略的逐回合结果和 `report.json`。权重改动只作用于评测期间加载的模型，报告保存来源哈希和改动坐标数，便于重放。

## 原理：把一行权重往参考词靠一点

设 `area` 原来的一行是 $w_a$，参考词的一行是 $w_r$，补丁给出的比例为 $s$，修改后的一行是：

$$
w_a' = (1-s)w_a + sw_r.
$$

例如 $s=0.5$ 会取两行的平均。对照评测跑三遍，分别用原权重、直接用 `zone` 替换、应用大模型给的补丁。仿真判分仍然依据方块最终到达了哪个目标区。

## 检查清单

- 先看 `diagnosis.json` 的 `reproduced`。没有复现差异时，选一份原指令能做对的浮点策略重新诊断。
- 用留出场景看 `paraphrase_success_gain`。只有改写成功数上升、两种原指令没有逐场退化，并且任一目标的改写成功数都没有下降，`accepted` 才为 `true`。
- 再看 `paraphrase_gain_over_synonym`，它表示补丁相对于直接复制 `zone` 嵌入多成功了几局。默认场景数适合教学演示，需要更充分的结果时可增加 `--seeds-per-split`。
