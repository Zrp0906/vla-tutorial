# 12_01｜监督微调进阶

[全部教程](../../README.md) · [进阶功能路线](12_进阶功能路线.md) · [下一篇：12_02｜QLoRA 进阶](12_02_QLoRA进阶.md)

## 这一部分介绍什么

阶段 06 用专家示范训练动作专家和相关投影。这里沿用同一套示范和 Flow Matching 损失，同时让梯度更新一部分 VLM 文本层。这样可以比较扩大解冻范围对动作学习和训练资源的影响。

## 使用说明与前提

先准备阶段 03–04 的训练与验证轨迹、训练集统计量，以及项目 `models/` 下的基础模型与处理器。`--run-dir` 指向生成数据时使用的目录，默认读取其中的 `config.json`。如果没有保存配置，可以用 `--config` 指定生成数据时使用的配置文件。

```bash
cd /Users/zrp/Desktop/lora
conda run -n embodiedai python smol/smol_workflow/p12_advance/12_01_train_sft.py --run-dir smol/outputs/lesson_run --device auto --epochs 1 --window-stride 200
```

示例训练 1 轮，每条轨迹每隔 200 帧取一个窗口。省略 `--window-stride` 和 `--epochs` 时使用配置中的值，`--batch-size` 默认是 1。用 `--text-layers` 设置解冻的文本层数，默认是 1。

## 输入和输出

- **输入**为基础权重、处理器、训练和验证动作窗口，以及仅用训练轨迹计算的归一化统计量。
- **输出**在 `--run-dir` 指定目录下的 `models/sft/`。`progress.json` 记录训练进度，`epoch_N/` 保存完整权重、运行配置与训练状态，`selected.json` 指向验证损失最低的检查点，`report.json` 记录训练结果。
- 已保存的 `epoch_N/` 可以由现有 `Runtime` 加载，也可以传给 12_03 的 `--base-checkpoint`。

## 原理：让更多层根据专家动作调整

和阶段 06 一样，训练先将专家动作和噪声混合，再让策略预测从专家动作指向噪声的速度。损失只统计有效的二维动作。变化发生在优化器更新的参数范围。

$$
\theta_{\mathrm{train}} = \theta_{\mathrm{action}} \cup \theta_{\mathrm{text,selected}}
$$

`θ_action` 是阶段 06 原本解冻的动作专家及相关投影，`θ_text,selected` 是这次额外解冻的文本层。视觉编码器保持冻结。以 16 个文本层为例，`--text-layers 1` 选中索引 14。最末层的文本输出不会再传给后续动作层，因此这里保留其冻结状态。

## 检查清单

- 在 `report.json` 的 `trainable_names` 中确认有动作相关参数和选中的文本层。
- 核对 `completed`、`frozen_unchanged` 和 `trained_changed`。再用 `selected.json` 找到待加载的完整检查点。
- 做同一数据上的对比时，保持训练和验证划分以及动作窗口设置一致。
